## 실물 Unity 실측 — 확인함 (2026-10-03)

시험용 Unity 프로젝트(Unity 6000.3 · Addressables 2.9.1)에 Unity API 로 그룹 4 · 라벨 3 · 항목을 넣고,
**Unity 가 직접 쓴 YAML·`.meta`** 로 `index` 를 돌렸다. 손으로 쓴 YAML 은 없다.

- 종료 0 · 항목 11 · 알림 0. `unityRoot` 는 `../..`.
- 주소·guid·kind·그룹·라벨·하위 에셋(스프라이트 4칸, 좌표는 Unity 꼴 그대로)·폴더 펼치기(`fromFolder`)·`includeInBuild:false` 가 넣은 것과 모두 맞았다.
- 실물 YAML 에서 처음 본 것 : 한글 주소는 따옴표 안에 유니코드 이스케이프로 적는다(바르게 풀림). 116자 주소도 접지 않고 한 줄로 적는다.
- 이 색인을 DataTool `validate`·`serve` 가 읽는 것까지 확인했다 (스튜디오 연동 설계 6절).
- 못 본 것 : 「낡은 색인」 경고의 실물 재현 · `Packages/` 안 에셋 · 프리팹·씬 kind.
