# AssetTool 2차 범위 조사 (2026-10-22)

> 루트 `Docs/Design/2026-09-23-AssetTool과DataTool연동설계.md` 5절의 2차 조각 6개를 무엇부터 할지 고른다. 설계는 아직 안 한다.

## 1. 결론 먼저

**추천은 안 A — Go 만으로 되는 둘(`Packages/` 훑기 → 읽기 전용 `serve`)부터. 서두르지 않는다.**

- **게임 저장소는 지금 Addressables 를 안 쓴다.** 패키지(2.9.1)는 깔려 있지만 `Assets/AddressableAssetsData` 가 없다(설정을 한 번도 안 만들었다).
  게임 쪽 조사(10-03)가 「지금 규모(빌드 12.6MB)에서는 Addressables 가 과투자, `Resources` 그대로. 빌드 50MB 를 넘거나 그림을 따로 내려받을 때 바꾼다」고 정했다.
  게임의 `.datatool.json` 에도 색인 칸이 없다. **그래서 2차 조각 여섯 모두 게임 저장소에서 지금 쓸 데가 없다.**
- 그러면 Unity 손 실측이 드는 길(B·C)은 지금 사용자 시간만 쓴다. 안 A 는 Unity 에디터 없이 자동 시험으로 끝나고, 게임이 Addressables 를 켜는 날 바로 쓸 수 있는 「보기」가 된다.
- 차례도 이미 정해져 있다 — AssetTool 2차는 ArtTool·AIMemoryTool 뒤 (mem 20261006-0ac1a5f6).

## 2. 조각 6개

| 조각 | 무엇 | 게임 저장소에서 지금 쓸 데 | 크기 | Unity 에디터 | 먼저여야 할 것 | 위험 |
| --- | --- | --- | --- | --- | --- | --- |
| `Packages/` 훑기 | 지금 `path:""` 로 들어가는 `Packages/` 에셋의 경로·kind 를 푼다 (아틀라스에 든 `Packages/` 텍스처 포함) | 없음 | S~M | 아니요 | 없음 | 패키지 실물은 `Library/PackageCache/` 에 있다 — Unity 를 한 번도 안 연 복사본엔 없다. 내장 패키지(`Packages/<이름>/`)·git 패키지·로컬 경로 패키지 꼴이 셋이다 |
| `serve` (보기) | 그룹·주소 목록 · 검색 · 썸네일 미리보기. 같은 색인·thumbs 를 읽는다 | 없음 | M | 아니요 | 없음 (thumbs 는 「없으면 썸네일 없음」) | 적다. DataTool `serve` 를 베낀다 — 127.0.0.1 · 시작 때 뽑는 토큰 머리 · `os.Root` 경로 감옥 · `ui/` 를 `embed` · 파일 확장자 표. 쓰기가 없으니 잠금·rev 는 안 가져와도 된다 |
| 규칙 파일 편집 | `asset-rules.json`(폴더 패턴 → 그룹·address·라벨) 을 웹에서 고친다. 폴더와 그 안 파일이 한 규칙에 같이 걸리면 막는다 | 없음 | M | 아니요 | `serve` · 규칙 파일 꼴(Unity 규칙 적용과 함께 정해야 한다) | 규칙 파일 꼴을 Unity 쪽 없이 먼저 정하면 나중에 바꾸게 된다 |
| Unity 규칙 적용 | 규칙 파일을 읽어 `CreateOrMoveEntry` 로 반영. 메뉴 · 임포트 때 · 배치 모드 | 없음 | M~L | 예 (`-nographics` 배치 모드로 됨) | **Unity 쪽 뼈대**(asmdef · Editor 폴더 · 검증 스크립트). AssetTool 엔 아직 `Unity/` 가 없다 | 임포트 때 자동 적용은 사람이 모르게 그룹을 옮긴다 — 끄고 켜는 법을 설계에서 정해야 한다 |
| 프리팹 썸네일 굽기 | 카메라로 찍어 `Library/AssetTool/thumbs/<guid>.png`(128×128 RGBA). 바뀐 프리팹만 | 없음 (게임 프리팹 13개) | L | 예 (**`-nographics` 없는** 배치 모드) | Unity 쪽 뼈대 | **가장 크다.** GPU 를 쓰는 배치 모드는 한 번도 안 돌려 봤다(연동 설계 6절 「어림」). 2D URP 스프라이트 프리팹의 경계 상자·투명 배경·「바뀐 것만」 판정도 다 새것 |
| 대조 매니페스트 | Unity 가 Addressables API 로 색인을 한 번 내서 Go 색인과 견준다 | 없음 | S~M | 예 (`-nographics` 로 됨) | Unity 쪽 뼈대 | 적다. 오히려 **할 일 「실물 Unity 로 I1 자료 뜨기」를 자동 시험으로 굳히는 길**이라 Go 색인의 정답지가 된다 |

DataTool 쪽 배치 모드 검증 꼴(`DataTool/Unity/Verify/verify.ps1`)은 `-batchmode -nographics -projectPath … -runTests` / `-executeMethod` 로 돈다. 대조·규칙 적용은 이 꼴을 그대로 베끼면 되고, 썸네일만 `-nographics` 를 빼야 해서 새로 재야 한다.

시험용 Unity 프로젝트에는 `AddressableAssetsData` 가 있어 Unity 몫 실측 자리는 이미 있다.

## 3. 안 셋

### 안 A — Go 만 먼저 (추천)

| 소단계 | 크기 |
| --- | --- |
| 1. `Packages/` 훑기 설계 (패키지 꼴 셋 · `PackageCache` 없을 때 알림) | S |
| 2. 구현 + 시험 자료 (`Testdata/` 에 내장·캐시 패키지 흉내) | S~M |
| 3. `serve` 설계 (DataTool 에서 베낄 것 · 화면 하나) | S |
| 4. `serve` 구현 + 크롬 headless 자동 판정 (DataTool `run.ps1` 꼴) | M |
| 5. 리뷰 · 고치기 | S |

- 사용자 몫 : **거의 없다.** 시험용 Unity 프로젝트를 Unity 로 한 번 열어 `PackageCache` 를 만들어 두는 것 정도.
- 얻는 것 : 연동 설계 5절 「`Packages/` 훑기」와 DataTool 이 쓰는 같은 색인의 「보기」. 할 일 「`Packages/` 에셋 실물로 보기」도 같이 닫힌다.

### 안 B — 규칙 길 (Unity 규칙 적용 + 규칙 파일 + 대조)

| 소단계 | 크기 |
| --- | --- |
| 1. Unity 쪽 뼈대 (asmdef · Editor · `verify.ps1` 베끼기) | S~M |
| 2. 대조 매니페스트 (Unity 가 색인을 내고 Go 가 견줌) — 뼈대 검증 겸 | S~M |
| 3. 규칙 파일 꼴 설계 + Go 검사(겹침 막기) | M |
| 4. Unity 규칙 적용 (메뉴 · 배치 모드, 임포트 때는 켜고 끄기) | M~L |
| 5. 규칙 편집 웹 — `serve` 가 있어야 하니 안 A 의 `serve` 를 먼저 하거나 뒤로 미룬다 | M |

- 사용자 몫 : Unity 메뉴 손 시험 · 임포트 때 자동 적용이 거슬리지 않는지 보기.
- 얻는 것 : 「폴더에 넣으면 주소가 붙는다」. **에셋이 수백 개를 넘어야 값어치가 난다** — 게임은 아직 아니다.

### 안 C — 썸네일 길

| 소단계 | 크기 |
| --- | --- |
| 1. Unity 쪽 뼈대 | S~M |
| 2. `-nographics` 없는 배치 모드 렌더 실측 (시간 · 창이 뜨나 · 무인으로 되나) | S (재기만) |
| 3. 썸네일 굽기 (경계 상자 · 투명 · 바뀐 것만) | L |
| 4. 웹에서 보이기 — DataTool `serve` 는 이미 thumbs 를 읽는다(2-3 계약) | S |

- 사용자 몫 : 썸네일을 눈으로 보고 괜찮은지 판정. GPU 렌더라 무인 실측이 막힐 수 있다.
- 얻는 것 : DataTool 표에서 프리팹 칸도 그림으로 보인다. 게임 프리팹이 13개라 지금은 없어도 된다.

## 4. 없어도 되는 것 (지금은)

- **프리팹 썸네일** — 게임 프리팹 13개, Addressables 안 씀. 위험만 크다.
- **Unity 규칙 적용 · 규칙 파일 편집** — 주소를 붙일 에셋이 아직 없다. 게임이 Addressables 를 켜는 날 다시 본다.
- **대조 매니페스트** — 게임엔 필요 없다. 다만 AssetTool 자체 시험(실물 정답지)으로는 값어치가 있어, Unity 쪽 뼈대를 만드는 날 첫 조각으로 넣는다.

## 5. 못 본 것

- `Packages/` 훑기 크기는 `Library/PackageCache/` 실물 꼴을 안 열어 보고 어림했다.
- `-nographics` 없는 배치 모드 렌더는 이번에도 안 돌려 봤다.
- 게임 저장소가 언제 Addressables 를 켤지는 모른다 — 게임 쪽 기준(빌드 50MB)만 봤다.
- 크기(S/M/L)는 코드 줄 수 비교(AssetTool 4.6K줄 · DataTool `serve` 2.9K줄)로 어림했고 `effort estimate` 는 안 돌렸다.
